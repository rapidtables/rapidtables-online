Convert numbers instantly between Decimal (Base 10), Binary (Base 2), Hexadecimal (Base 16), Octal (Base 8), and ASCII characters.

Number Base Systems Overview

  • Decimal (Base 10): Standard number system using digits 0 through 9.
  • Binary (Base 2): Used in computing, consisting exclusively of 0s and 1s.
  • Hexadecimal (Base 16): Uses digits 0–9 and letters A–F to represent byte values compactly.
  • Octal (Base 8): Uses digits 0 through 7, historically used in computing and file permissions.
