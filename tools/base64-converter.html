What is Base64 Encoding?

Base64 is a binary-to-text encoding scheme that represents binary data in an ASCII string format by translating it into a radix-64 representation. Each 6 bits of binary data is mapped to one of 64 ASCII characters (A-Z, a-z, 0-9, +, /).

It is commonly used when transferring data over media designed to deal with textual data (such as emails via MIME or embedding data in HTML/CSS URLs).
