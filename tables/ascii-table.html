What is ASCII?

ASCII stands for American Standard Code for Information Interchange. It is a character encoding standard for electronic communication. Standard ASCII uses 7 bits to represent 128 characters (numbered 0 to 127).

  • 0 - 31: Control characters (e.g. Null, Backspace, Line Feed, Carriage Return, Tab).
  • 32: Space character.
  • 33 - 126: Printable characters (numbers 0-9, letters a-z, A-Z, punctuation marks).
  • 127: Delete control character (DEL).
