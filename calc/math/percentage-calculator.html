How to Calculate Percentage

A percentage is a number or ratio expressed as a fraction of 100. It is often denoted using the percent sign, "%".

1. Percentage of a Value Formula

To find P% of number X:

Result = (P / 100) × X

2. What Percent is X of Y?

To determine what percentage number X is of total Y:

Percentage = (X / Y) × 100%

3. Percentage Change Formula

To calculate the percentage increase or decrease between initial value V1 and new value V2:

Percentage Change = ((V2 - V1) / |V1|) × 100%

If the result is positive, it represents an increase. If the result is negative, it represents a decrease.
