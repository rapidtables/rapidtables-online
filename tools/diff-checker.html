Text Difference Checker

Compare two text files or code snippets and visually highlight differences line-by-line.

How Diff Checker Works

A diff tool calculates the difference between two files using the Longest Common Subsequence (LCS) algorithm:

  • Green Lines: Content added to the new modified version.
  • Red Lines: Content removed or replaced from the original version.
  • Gray Lines: Identical unchanged lines.
